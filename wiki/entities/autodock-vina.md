# AutoDock Vina Molecular Docking Engine

## Overview
**AutoDock Vina** is an open-source program for molecular docking and virtual screening developed by Dr. Oleg Trott. It significantly improves docking speed and binding mode prediction accuracy over previous AutoDock generations using iterated local search global optimization algorithms.

## Key Capabilities
- Multithreaded grid-based conformational search.
- Knowledge-based and empirical scoring function for binding free energy ($\Delta G_{\text{bind}}$ in kcal/mol).
- Automated flexible receptor side-chain modeling and multi-ligand screening.
